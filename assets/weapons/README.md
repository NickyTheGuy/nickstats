# Combat marker silhouettes

Unmodified Valve CS2 equipment/kill-feed silhouettes, extracted by
https://github.com/Juknum/counter-strike-icons at commit
`57a08657e1c2f1e6875c8b79575c23d4b6eb285a`.
Source: `cs2/panorama/images/icons/equipment/<name>.svg`.
Artwork belongs to Valve Corporation. The analyzer loads only locally bundled,
allowlisted icons used in the selected replay. Grenade kills reuse the matching
assets under `assets/grenades/`. Unsupported weapons use a generic kill marker;
headshot artwork is not used for ordinary kills.
